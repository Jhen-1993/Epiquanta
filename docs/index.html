BEFORE YOU BEGIN

開始前，
先了解這幾件事。

從安裝到下次啟動，保留完整資料夾即可沿用同一套操作方式。

能直接在 GitHub 網頁上分析嗎？

不能。GitHub Pages 展示的是靜態介紹與下載頁，無法執行這套 R／Shiny 後端。請下載 Releases 的完整套件，在自己的 Windows 電腦啟動。

要下載 Releases，還是 Code → Download ZIP？

一般使用者請到此專案 GitHub 的 Releases，下載 Epiquanta_Windows.zip。Code → Download ZIP 是原始碼版，沒有預先安裝的 library 套件，需要另外安裝相依套件。

查看完整套件與安裝步驟 →

按啟動檔沒有成功，怎麼辦？

先確認已完整解壓縮，並安裝 Windows x64 的 R 4.5.x。保留啟動時的錯誤訊息，查看 logs/server-error.log 與 logs/launcher-error.log。若提示缺少套件，執行 Install_Dependencies.cmd。若 8765 被其他程式占用，先關閉該程式再重啟。

安裝後還需要網路嗎？

完整套件與 R 安裝完成後，啟動及分析可在本機進行。首次下載 R、完整套件或補裝 R 套件需要網路；本程式沒有上傳研究資料到雲端分析的流程。

大型資料集如何使用？

進入工作室後選「本機大檔（免上傳）」，先讀取欄名並選擇必要欄位。資料與模型矩陣仍使用記憶體，所需 RAM 可能高於檔案大小。詳細操作可在工作室的「方法與操作」查看。

結果可以直接當作研究結論嗎？

結果反映你指定的資料與模型，仍需檢查研究設計、資料品質、模型假設及估計限制。軟體不會代替研究者決定變項、刪題或判定因果。
