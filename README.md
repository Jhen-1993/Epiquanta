# Epiquanta

本 Repository 只放公開入口網站、下載導引與法律文件。
統計分析不能在 GitHub Pages 執行；請到 Releases 下載完整 Windows 套件。

目前版本：v1.0.1

## 使用方式

1. 從 Releases 下載 `Epiquanta_Windows_v1.0.1.zip`。
2. 完整解壓縮。
3. 安裝 Windows x64 R 4.5.x。
4. 雙擊 `Start_Epiquanta.cmd`。
